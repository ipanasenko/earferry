This service allows user to add their YouTube video link and get an MP3 file back in a podcast feed. Then user can listen to the YouTube videos in any podcast app they want.

The whole project consists of three repos:
- This one: It's a public-facing multi-user service.
- Second one: It's a sibling folder called `listen-later`. This is a private copy of the same service that I keep only for myself just in case the public one will get blocked.
- And the third piece is used by two other projects. It's actual media extractor from YouTube. Its path, also a sibling project, it's called `earferry-extractor`.

You are allowed to make changes in all three repos.
